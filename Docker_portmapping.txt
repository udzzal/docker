Port Mapping:

            Port mapping in Docker (also known as port publishing or port forwarding) bridges
             network traffic between  our host machine (our physical computer or server) 
            and an isolated Docker container.

        


Port mapping connects a port on your computer (host) to a port inside the container.

Basic syntax
docker run -p HOST_PORT:CONTAINER_PORT IMAGE

For example:

docker run --name my-nginx -p 8080:80 nginx

Here:

Your Computer                    Docker Container
──────────────                   ─────────────────
localhost:8080  ──────────────→  port 80

So when we open:

http://localhost:8080

the request is forwarded to port 80 inside the Nginx container.

Remember this
-p 8080:80
   │    │
   │    └── Container port
   └─────── Host port



Another example: Node.js
If your Node.js application listens on port 3000:

docker run --name node-app -p 3000:3000 node-app

Then access:

http://localhost:3000
